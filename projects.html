Real Time Anomaly Detection Engine

Machine Learning Systems

A streaming anomaly detection system that ingests live server metrics through Apache Kafka and runs three models in parallel: an Isolation Forest, an LSTM autoencoder in PyTorch, and Z score control charts. Each catches a different kind of anomaly, and a weighted voting layer combines them into one confidence score. In benchmarks the ensemble beat the best single model on F1 while cutting false positives by over 20%. A live Streamlit dashboard tracks scores in real time, FastAPI serves results, MLflow tracks every run, and the whole stack starts with one docker compose command.

German Credit Risk Classification

Machine Learning

An end to end supervised pipeline on 1,000 credit records with 20 features. I benchmarked Logistic Regression, KNN, Random Forest, and XGBoost with 5 fold cross validated GridSearchCV, optimizing on F1 because the classes are imbalanced. XGBoost won with a test F1 of 0.5946, beating every baseline by up to 14%. Preprocessing runs inside sklearn Pipelines with IQR outlier capping, one hot encoding, and scaling, so nothing leaks between training and evaluation.

Hospital Readmission Risk Scorer

Machine Learning · Healthcare

A patient readmission risk scoring system built on public CMS hospital data. I engineered more than 30 behavioral and clinical features entirely in SQL, things like prior visit frequency and diagnosis complexity, to predict 30 day readmission risk. The XGBoost classifier reached an AUC of 0.82 on held out data, with a SHAP layer that explains the top risk drivers for each patient. A Streamlit dashboard tracks predicted scores against actual outcomes to keep the model honest after deployment.
