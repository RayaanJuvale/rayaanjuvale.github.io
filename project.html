🔍 Gender Pay Disparity Analysis

Led a comprehensive statistical analysis of gender-based pay disparities using a Glassdoor dataset containing employee-level data. Identified an average base pay gap of $8,304 between men and women across different departments. Developed and deployed a multiple regression model that achieved 65.8% variance explanation in base pay through factors including gender, education, seniority, and department. The analysis revealed department-specific patterns, with Engineering showing the largest pay gap while some departments showed mixed bonus patterns. Created visualizations using R and ggplot2 to effectively communicate findings and provide actionable insights for reducing workplace disparities.

💊 Drug Adverse Events Analysis: Ozempic vs Metformin

Analyzed adverse event reports from the OpenFDA API to compare safety profiles between Ozempic and Metformin, two major diabetes medications. Built a robust ETL pipeline that fetches, cleans, and processes adverse event data while handling API pagination limits and nested JSON structures. The analysis examines the most commonly reported side effects, severity patterns, and patient demographics for both drugs. This project demonstrates skills in API integration, data wrangling with complex nested data structures, and healthcare data analysis. Created comprehensive visualizations to communicate findings about how the newer drug (Ozempic) compares to the traditional option (Metformin) in terms of patient-reported adverse events.
